# User workflow

1. **Select job.** Choose site, material class and target-surface checklist. The
   app refuses unsupported materials.
2. **Self-check.** Mount camera/projector, warm up, scan reference cassette and
   pass dark/flat/reference-consensus checks.
3. **Acquire.** Follow view prompts. Each view captures primary and controlled
   states; incomplete frames are rejected automatically.
4. **Review map.** Green = optical proxy PASS, red = FLAG, gray = UNKNOWN or not
   visible. Coverage percentage is shown separately from outcome.
5. **Act.** Reclean red areas, correct setup and reacquire gray areas. Never turn
   gray into green by operator override.
6. **Escalate.** Use the approved ATP, protein, chemistry or microbiology method
   when biological/chemical specificity is needed or UNKNOWN persists.
7. **Close job.** Export view IDs, reference IDs, timestamps, outcomes, coverage,
   inaccessible areas, repeats and deviations.

Suggested report language: “No modeled optical-transfer deviation was detected
within the visible validated surface class” rather than “clean,” “safe,” or
“sterile.” Training must explicitly cover scope, reference care and escalation.
