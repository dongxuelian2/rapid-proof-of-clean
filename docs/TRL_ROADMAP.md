# TRL roadmap

Current estimate: **TRL 2** (technology concept formulated with analytical and
synthetic evidence). This is a self-assessment, not an external certification.

| Gate | Exit evidence | Decision |
| --- | --- | --- |
| TRL 2 → 3: proof of concept | calibrated bench rig; raw-data repeatability; at least one named material/residue response; reference corruption and invisible controls; locked coupon protocol | stop or narrow if physical contrast is absent |
| TRL 3 → 4: laboratory validation | preregistered blinded coupon set; material-specific error/UNKNOWN intervals; measured nuisance bounds; measured timing; prototype BOM | proceed only for passing strata |
| TRL 4 → 5: relevant environment | cleanable field prototype; safety review; guided workflow; two professional sites; coverage audit; comparison with ATP/visual/chemical checks | redesign if workflow or coverage targets fail |
| TRL 5 → 6: demonstrated prototype | multi-site prospective study; maintenance/reference lifecycle; cybersecurity/data controls; operator training validation; manufacturing plan | define product claim and regulatory route |

Milestones are evidence gates, not dates. The first critical experiment is
physical observability, not feature expansion.
