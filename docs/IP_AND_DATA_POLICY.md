# IP and data policy

This is an internal working policy for the repository. It does not replace official challenge terms, contracts, or legal advice.

## Commit allowed

- our source code
- our notes
- our summaries
- public citation metadata
- our experiments
- proposal drafts
- generated plots

## Do not commit by default

- challenge files with unclear redistribution rights
- confidential documents
- personal account exports
- credentials
- cookies
- tokens
- API keys
- raw proprietary datasets

If future review confirms that a specific challenge data file may be publicly redistributed, make a separate decision first. Record the source, permission basis, provenance, and intended location before adding it to Git.
