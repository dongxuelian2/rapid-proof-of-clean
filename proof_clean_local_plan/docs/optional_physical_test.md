# 可选零采购小样验证协议

这个协议不属于纯计算必需步骤，相关相机采集和图像配准程序尚未包含在默认实现中。已有笔记本摄像头与屏幕、已有安全反光小样足够形成探索性采集的前提时才尝试；没有合适条件就记录未实测。不要购买设备，不进行任何微生物培养或识别，不将液体或残留物接触电脑。

## 目的和停止条件

先只验证“安全残留相对于同一小样的参考能否产生可重复的调制变化”。不尝试测细菌，不宣称定量油膜厚度。参照称为“按记录方法清洁后的基准”，不要称为绝对无残留。若摄像头看不到小样上的屏幕条纹反射，调整外部小样的位置与角度；仍无法观察就终止，不能要求模型合成替代观测。

使用手边已有的可擦拭镜面或光滑样品；开始只取一种材质。由参与者记录材质、已有清洁方法和样品身份。任何水、食用油、擦拭布都在远离笔记本的独立操作处使用；物品处理完并确认外部无滴液后再放到观察位置。第一次实验可以用已有指纹残留，不需要制备任何生物材料。

## 采集准备

在屏幕上显示灰度正弦条纹，频率2、4、8、16、32、48周期/完整显示宽度，两个方向，每频依次0、90、180、270度相位。使用与程序相同的序列命名，保存原图；拍摄间等待屏幕及摄像头刷新稳定。该等待时间应记录并实测，不得假设一帧显示后立即得到对应相机帧。相机的自动曝光、白平衡、锐化、降噪、压缩和伽马都会影响模型；能够锁定就锁定，不能锁定就记录为限制。普通8位视频不等于线性测量，需单独校准或仅作定性演示。

不要让采集窗口、桌面通知或鼠标图案覆盖有效条纹。镜面样品须保持位置、焦点和角度；处理后重新摆放时做配准，但插值误差应另计。摄像头没有方便的采集接口时使用系统已有录像工具保存原始视频及时间戳，之后手工标记每个条纹阶段；不要让模型猜帧号或伪造同步精度。

## 对照设计

至少包含基准重复、加入安全残留、移除后复测、只重新摆放但不加残留、不同亮度、轻微离焦、已有划痕/材质纹理、低信号区域。不能故意损伤样品来制造划痕；没有已有划痕样品则把该实物对照记为缺失。每种状态至少做三次独立重新摆放；帧的重复与样品/摆放的独立重复分别编号。先用一个样品开发；有其他已有样品时留出至少一个完整样品或整个独立采集时段作为盲测，不能将同一次视频的邻帧分到训练和测试。

## 文件结构与元数据

原始图片用 `raw/<sample_id>/<session_id>/<state>/<orientation>_f<cycles>_p<phase>.png`；使用视频时保存原视频并另存frame_index.csv。每个session保存metadata.json：sample_id、session_id、时间、操作者、摄像头型号、可知的相机设置、屏幕亮度、显示像素大小、距离/角度的测量方式、状态制备说明、参照来源、同步方式、是否线性化、缺失项。无法获得的字段用null及原因，不编造。

## 先分析原始信号，再谈检测器

先检查四相位关系、饱和、重复性、图案与拍摄帧同步和样品位置。用实际反射序列算调制图，比较独立重复之间的自然变化和加残留后的变化；自然变化与残留变化完全重叠时，该配置不支持检测。直接把仿真q阈值和ε套在相机8位JPEG上不成立，应保留定性结果或重新建立测量模型与误差校准。

没有已知残留质量、厚度或标准参照的实验，只能报告本批样本上的识别/异常分离情况，不能给真实浓度检出限。成功的小样演示为实验原理验证增加证据，整室能力、材质泛化和创新性仍需另外验证。保留所有失败实验及完整原图；没有好结果也比伪造原理验证有价值。
