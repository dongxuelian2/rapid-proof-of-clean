# 计算模型与可核验的条件性结论

## 变量和适用条件

对每个表面位置和一个条纹方向，令屏幕空间频率为 f_j（周期/屏幕坐标像素），x_j=2π² f_j²。清洁参照的等效反射传递模糊方差为 v；样品相对参照的清洁状态几何/焦点差异为 b，假设 |b|≤b_max；待测残留引入的额外方差为 q≥0。这里采用高斯反射传递核近似。q 是一个模型代理量，它与真实油量、膜厚、微生物负荷之间的关系尚未建立。不同方向分别使用 b、q。

模型规定参照和样品的相位调制幅值分别为 M_ref,j = B g_ref exp(-x_j v)，M_sam,j = B g_sam exp[-x_j(v+b+q)]。同一方向、同一位置上的 g_ref/g_sam 在全部频率间保持不变；于是 z_j=log(M_ref,j/M_sam,j)=a+x_j t，其中 a=log(g_ref/g_sam)，t=b+q。相位可以随表面位置变化，但在一次四相位序列内须满足既定相移关系。

高斯传递核及频率响应是一种可计算近似；已有结构光污染检测论文为相关机制提供先例，没有为本项目的这组参数、残留物假设或检测阈值提供实测标定。均匀吸收可能只改变 a，完全不改变 q，这就是本模型不能检测所有残留物的一个明确反例。

## 四步相移和误差传播

四帧为 I_k=A+M cos(φ+kπ/2)+e_k，k=0,1,2,3。设每帧线性亮度误差满足 |e_k|≤ε，并且没有饱和裁切。程序恢复 M_hat = 0.5 sqrt[(I_0-I_2)²+(I_3-I_1)²]。两项差分分别受至多 2ε 的扰动，由欧氏范数的反三角不等式可得 |M_hat-M|≤√2 ε。

仿真中的 ε = additive_noise_bound + 0.5/(quantization_levels-1)。这是生成器已知的确定性界；现场相机通常无法仅凭少量帧的最大观测误差获得真正的全情形误差界。拿经验最大值当确定性硬界需要额外依据，不能直接照搬本结论。

令 Δ=√2 ε。当两个幅值均大于 Δ 时，z_j 属于区间：

L_j = log[(Mhat_ref,j-Δ)/(Mhat_sam,j+Δ)]；
U_j = log[(Mhat_ref,j+Δ)/(Mhat_sam,j-Δ)]。

实际程序使用更保守的信号门槛 3Δ。任何频率信号太低、相位闭合关系异常、像素饱和或外部可见性掩码无效，该位置直接 UNKNOWN。闭合检查是必要的局部检查，无法识别所有与编码同步的系统性干扰。

## 可行斜率的精确区间

寻求所有满足 L_j≤a+x_j t≤U_j 的 a、t。给定 t，各个约束对应 a 的闭区间。实直线上有限闭区间有公共交集，当且仅当任意两者相交。由于 x_j 严格递增，对每个 j>k，可行 t 必须且只须满足：

(L_j-U_k)/(x_j-x_k) ≤ t ≤ (U_j-L_k)/(x_j-x_k)。

对所有频率对取左端最大值、右端最小值，得到 [t_L,t_U]。若区间为空，数据不符合模型或声明误差范围，输出 UNKNOWN。由 q=t-b、|b|≤b_max、q≥0，得到 q_L=max(0,t_L-b_max)，q_U=t_U+b_max；若 q_U<q_L，同样输出 UNKNOWN。

## 判定和保证的准确范围

两个条纹方向均可行且 q_U<q_crit 时才 PASS；至少一个方向 q_L≥q_crit 时 FLAG；其他情况 UNKNOWN。阈值 q_crit=0.5 pixel² 只是本包预设的代理量门槛，不是法规或卫生学标准。

在所有模型与误差假设成立、参照确实对应所述清洁基准、可见性掩码正确时，实际 q 包含在上述区间中。因此，q≥q_crit 的可见位置不会被该规则判为 PASS。这是确定性、模型条件下的包含关系，不是“真实世界误差率为0”的经验结论，也不是“95%概率无菌”。

删除频率只会减少约束，因此精确可行集不会变小；加入频率后可行集不会变大。更多频率未必显著改进实用性能，还可能使额外真实噪声触发质量检查，这需要数据评估。空间位置没有观测时不存在该证书，不能从相邻位置外推。

## 不可辨识性必须保留

若两个物理状态在全部可用观测下产生完全相同的数据，任何仅使用这些数据的算法均不能区分二者。本包的光学不可见残留、已污染参照和抵消性几何变化展示了不同形式的不可辨识性。想扩展到这类情况，需要新的可验证观测或更严格的适用范围；增加网络参数无法创造缺失的测量信息。
