# 可选扩展规格：视图级逐次测量

状态：尚未实现。这个扩展不能列入当前已完成结果。

函数接口：`adaptive_infer(reference, sample, config, visible)`。输入仍为完整已生成序列，只能按已选择的频率索引读取；初始索引[0,5]。调用已有infer后，在visible且关键区域内检查UNKNOWN。若该视图没有UNKNOWN就停止；否则增加索引3，再检查；仍有UNKNOWN则加入剩余索引1、2、4，最多使用6频。返回status、chosen_indices、frames_requested、stop_reason。每频需要2方向×4相位；若同次获取参照和样品，帧数加倍。不能按像素分别计费后声称相机只拍了这些像素的帧，计费单位是整幅视图。

先在独立开发种子上选择追加顺序。测试种子禁止再调整。比较相同场景的固定2频、固定6频和自适应；至少报告均值及最差视图帧数、代理量错误PASS、UNKNOWN和完整预算。先验关键区域须由操作者/场景定义，不能由污染真值决定。

新增测试：自适应输出不读取真值；调用的每次索引严格增大；数据不变时可行集只能收缩；最多48样品帧；边界样本到预算尽头仍应UNKNOWN；以相同完整数据计算的六频与自适应最终六频结果一致。

注意：更多测量无法消除错误物理假设、污染参照、光学等价状态。确定性界只在误差确实被该界覆盖时成立；现场改用统计界后，序贯停止还需要重新设计有效的统计校准，不能直接沿用保证。
