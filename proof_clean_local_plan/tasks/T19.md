# T19 · 把现场流程和合作需求写成可交付承诺

执行者：参与者决定。先遵守 AGENTS.md。本卡完成前不得声称后续任务已完成。

在 human/deployment.md 描述后续现场流程：确认可用参照与材质范围；在待测视图投放条纹；完成质量检查；计算区间；记录需要复查与无法确认区域；对目标表面的覆盖进行审计。使用 time_budget 的公式重算完整时间，包括参考采集、移动、复拍与报告。所有待验证性能写成目标。

合作需求应具体：由合作方提供目标材质和真实残留样本、可借用成像设备、现有清洁流程、独立残留量/卫生参照测量及操作人员测试；参与者负责软件、模型、数据分析与可复现验证。本人本轮零采购，不等于后续产品没有成本。需要报价却尚无报价时标“待报价”，不编造传感器单价。下一卡 T20。
