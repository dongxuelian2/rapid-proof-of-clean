# T03 · 创建独立环境并记录机器

执行者：本地模型执行。先遵守 AGENTS.md。本卡完成前不得声称后续任务已完成。

输入为解压后的完整目录。Linux/macOS 依次运行下面三条命令；Windows 使用 README.md 的对应解释器路径：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_pipeline.py doctor
```

后文的 PY 表示实际使用的虚拟环境 Python 路径：Linux/macOS 为 .venv/bin/python，Windows 为 .\.venv\Scripts\python.exe。执行时用该路径替换 PY；不要原样输入 PY。验收是 outputs/environment.json 存在，记录 Python、NumPy、平台及代码/配置哈希，且 gpu_required 为 false。若 NumPy 导入失败，在同一解释器中安装它；不要切换云计算。下一卡 T04。
