# T17 · 保存原始小样证据并独立盲测

执行者：参与者人工；可选。先遵守 AGENTS.md。本卡完成前不得声称后续任务已完成。

按 docs/optional_physical_test.md 执行。这个文件包含采集序列、对照、命名、重复、数据分组及停止条件。原始图像不得覆盖；所有摄像头自动设置、屏幕亮度、样品、距离、角度、日期和序列写进元数据。先做是否能区分残留响应的可行性实验，不能把仿真误差界直接用于现场确定性证书。

验收是至少有真正独立的小样/重新摆放对照、原始照片、未参与调参的测试组和如实失败记录。没有质量合格的数据就保留失败，不能画替代照片，也不能把相邻视频帧当独立样品。通过与否均进入 T18。
