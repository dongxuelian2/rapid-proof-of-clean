# T11 · 生成报告并验收完整性

执行者：本地模型执行。先遵守 AGENTS.md。本卡完成前不得声称后续任务已完成。

依次运行 `PY run_pipeline.py report` 与 `PY check_outputs.py`。读 outputs/report.md、summary.json 和 integrity_check.json。默认数据完整性检查必须通过；其中未声明真实物理检出率、未认证新颖性、未认证系统TRL是正确状态，不属于待“修复”的错误。

人应对照原始 CSV 核查至少三项数字，例如错误PASS数量、UNKNOWN数量与总像素数量。若六频只比两频略有改进，报告必须保留这个事实。报告不得直接用于投稿，因为其中没有人的原创贡献、真实部署证据或完整创新性论证。下一卡 T12。
