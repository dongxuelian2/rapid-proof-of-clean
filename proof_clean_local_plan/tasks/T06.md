# T06 · 运行数学与程序单元测试

执行者：本地模型执行。先遵守 AGENTS.md。本卡完成前不得声称后续任务已完成。

运行 `PY run_pipeline.py tests`。读 outputs/tests.txt 和 test_results.json，默认应运行8项测试且 failures=0、errors=0。测试涵盖四相位恢复、幅值误差界、斜率区间、真值包含、盲区拒判、增加频率的可行集关系、高斯核数值核对和异常输入数值稳定性。

任何一项失败时先保存完整错误，不运行性能评估，不修改测试预期以使其通过。检查是否用了错误目录、缺失文件或不兼容环境；两次仍失败，停止该卡并留下失败记录。通过单元测试只能说明对应程序行为符合这些测试，不能说明真实油污可检出。下一卡 T07。
