# Project scope

This document defines the boundary of the Rapid Proof of Clean research workspace. It does not select a technical solution.

## In scope

- challenge rules audit
- literature scouting
- technology landscape analysis
- feasibility analysis
- quantitative modeling
- simulations
- small computational experiments
- proposal drafting
- evidence / claim auditing
- submission preparation

## Out of scope for Phase 0

- selecting a sensing modality
- committing to a biological mechanism
- building hardware
- selecting a commercial product architecture
- writing the final proposal
- claiming novelty before prior-art review

Phase 0 covers infrastructure, challenge intake scaffolding, reproducibility, and research bookkeeping only.
